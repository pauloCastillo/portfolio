# 🚀 Portfolio Profesional – Desarrollo Web & Mobile

Portfolio profesional desarrollado con **Next.js (App Router)** y **TypeScript**, enfocado en **SEO técnico, rendimiento, escalabilidad y conversión**.

Este proyecto representa mi perfil como **desarrollador de software**, orientado a clientes profesionales que buscan soluciones reales en aplicaciones web y móviles.

---

## 🧠 Enfoque del proyecto

El objetivo de este portfolio no es solo mostrar código, sino demostrar:

- Capacidad para diseñar **soluciones de negocio**
- Buenas prácticas de **arquitectura frontend moderna**
- Optimización para **SEO y posicionamiento en buscadores**
- Enfoque en **experiencia de usuario y conversión**

## 🛠️ Stack Tecnológico

- **Framework:** Next.js 14+ (App Router)
- **Lenguaje:** TypeScript
- **UI:** Componentes semánticos + CSS moderno, Tailwindcss
- **SEO:** Metadata, Sitemap, Robots.txt
- **Performance:** Lazy loading, optimización de rendering
